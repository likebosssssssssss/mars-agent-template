# Переавторизация Claude

Если бот перестал отвечать, отвечает мгновенно пустыми/обрезанными сообщениями, или пишет «Not logged in» — у Агента истёк «пропуск» к Claude. Есть два способа починить: простой (через Telegram, 1-2 минуты) и запасной (через терминал сервера, если бот вообще не отвечает даже на команды).

Обычно пропуск обновляется автоматически, без Вашего участия. Но раз в год-два может понадобиться ручное обновление — это нормальная процедура безопасности.

---

## Способ 1 (основной): команда /reauth через Telegram

**Работает даже когда Claude не отвечает** — сама команда `/reauth` обрабатывается кодом бота напрямую, не через Claude, так что срабатывает всегда, если бот-процесс вообще жив (проверить: `systemctl is-active agent-bot`).

1. Откройте чат с ботом в Telegram
2. Напишите `/reauth` (или откройте `/settings` → **🔑 Переподключить Claude**)
3. Бот пришлёт кнопку **«🔗 Авторизоваться в Claude»** — нажмите её (откроется Ваш обычный браузер)
4. Войдите в аккаунт Claude (с подпиской Pro/Max), нажмите **Authorize**
5. Браузер покажет страницу с ошибкой («сайт недоступен», `localhost:16424`) — **это нормально и ожидаемо**, не пугайтесь
6. Скопируйте **весь адрес целиком** из адресной строки браузера (там будет `...code=...`)
7. Вставьте этот адрес обычным сообщением **в чат с ботом** (не в терминал!) — бот сам обменяет код на токен, запишет в `.env` и перезапустится

Копирование тут — обычное, через Telegram и адресную строку браузера на своём компьютере, никаких терминалов и VNC не нужно.

**Если что-то пошло не так на шаге 6-7:** ссылка одноразовая и живёт 10 минут — если не успели, начните заново с `/reauth`.

## Способ 2 (запасной): через терминал сервера

**Использовать только если способ 1 не сработал** — то есть бот вообще не реагирует ни на какие команды в Telegram (сам процесс завис или упал, не просто протух пропуск Claude).

Это долгий и неудобный путь (VNC-консоль Beget или VS Code Tunnel — оба капризны: копирование/вставка в них часто не работает, вводить длинные строки приходится руками). Прежде чем начинать — по возможности попросите Claude Code открыть страницу авторизации браузером и получить готовый короткий код, чтобы не переписывать вручную огромный URL.

### Шаг 1. Подключитесь к серверу

Через VS Code Tunnel (Remote Explorer → Tunnels → сервер) или через консоль Beget (беget.com → ваш VPS → «Консоль»).

### Шаг 2. Переключитесь на пользователя бота

```
sudo -u agent -i
```

Промпт должен стать `agent@...:~$` (не `#`).

### Шаг 3. Запустите вход в Claude

```
claude /login
```

- «trust this folder» → `1` → Enter
- Выберите **1. Claude account with subscription**

### Шаг 4. Авторизуйтесь

Появится длинная ссылка `claude.com/cai/oauth/authorize?...`. Откройте её в браузере, войдите, нажмите Authorize — появится короткий код вида `код#state`.

**Важно:** если копирование/вставка в терминал не работает (частый случай на VNC-консолях) — наберите код вручную по буквам, отдельно обращая внимание на 0 (ноль) / O (буква) / o (строчная буква) — они легко путаются в моноширинном шрифте. Код одноразовый и короткоживущий (~1-2 минуты) — если не успели, `Enter` для повтора и берите свежую ссылку.

### Шаг 5. Перезапустите бота

```
exit
sudo systemctl restart agent-bot
```

## Если через сутки опять перестанет работать

Значит «хвосты» от старого входа мешают автоматическому обновлению:

```
sudo sed -i '/^CLAUDE_CODE_OAUTH_TOKEN=/d' /home/agent/.agent/.env
sudo sed -i '/^CLAUDE_CODE_OAUTH_REFRESH_TOKEN=/d' /home/agent/.agent/.env
sudo sed -i '/^CLAUDE_CODE_OAUTH_SCOPES=/d' /home/agent/.agent/.env
```

Затем повторите Способ 1 или 2. После этого «хвостов» не останется.

---

## Типичные ошибки

- **«claude: command not found»** — Claude Code не установлен у этого пользователя (`which claude` под нужным пользователем)
- **Код из способа 1 не принимается** — ссылка одноразовая, начните `/reauth` заново
- **Копирование в терминал (способ 2) не работает вообще** — известная проблема некоторых VNC-консолей (например Beget), это не баг с вашей стороны — переходите на набор вручную или используйте способ 1
- **Браузер ругается на аккаунт** — убедитесь, что залогинены под аккаунтом с подпиской Claude Pro/Max
